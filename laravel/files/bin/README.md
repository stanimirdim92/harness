# bin/

Project scripts. Run them from the checkout root.

## Checkout setup

| File                       | Purpose                                                                                                                                                                                    | Usage                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| `worktree-setup.sh`        | Installs PHP and JavaScript dependencies so that they match `composer.lock` and `yarn.lock`, including after an incomplete install. Needs `.env` and `.env.testing`.                       | `bin/worktree-setup.sh` (`--build` also builds and checks `public/build`) |
| `worktree-doctor.sh`       | Read-only readiness check. `--infrastructure` compares this checkout's runner version with the main checkout. `--frontend` checks for a complete Vite build.                               | `bin/worktree-doctor.sh --infrastructure`                                 |
| `worktree-runtime.version` | Version number of the test runner infrastructure. `worktree-doctor.sh` fails when a checkout is older than the main checkout. Raise it only when every checkout must take a runner change. | Data file                                                                 |
| `setup-quality.sh`         | Installs the pinned pre-commit hooks and sets `core.hooksPath=.githooks`. Run it after `worktree-setup.sh`.                                                                                | `bin/setup-quality.sh`                                                    |
| `pre-commit.py`            | Downloads (only with `--setup`), verifies by checksum and runs the pinned pre-commit release. The hooks are in `.pre-commit-config.yaml`.                                                  | `python3 bin/pre-commit.py run --hook-stage manual --files FILE`          |

## Backend tests and test databases

| File                     | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Usage                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| `worktree-test.sh`       | The only supported backend test entry point, called by `composer test`. Gives each checkout its own MySQL databases and each test process its own block of database indexes on the shared local Redis server, then runs Pest in parallel. Handles `--type-coverage`, `--profanity`, `--mutate`, `--tia` and every `--coverage*` option (it loads PCOV for the checkout), and stops any Playwright server that this run's browser tests leave behind. Needs `setpriv`. See [TESTING.md](../TESTING.md). | `composer test -- [Pest options]`                                                |
| `schema-snapshot.php`    | Helper for the runner and `schema-refresh.sh`. `refresh` dumps the schema of the local `leadbuster` database. `template-check` and `template-build` check and build the shared read-only template database `leadbuster_tpl_<fingerprint>_<checksum>`.                                                                                                                                                                                                                                                  | Called by other scripts                                                          |
| `schema-refresh.sh`      | Publishes a new schema snapshot from the local `leadbuster` database after an intentional schema change, and rebuilds this checkout's template. Commit the three files in `database/schema/` together.                                                                                                                                                                                                                                                                                                 | `bin/schema-refresh.sh`                                                          |
| `worktree-databases.php` | Lists test databases by owning checkout and removes those of deleted checkouts, including their `_template` databases and the worker baselines kept in `/tmp/leadbuster-tests-<uid>/`, and removes the owner record afterwards. A full sweep also removes orphaned `leadbuster_test_stage_*` and `leadbuster_test_backup_*` databases when no test run is active. Dry run by default.                                                                                                                  | `php bin/worktree-databases.php --checkout /abs/path` then repeat with `--apply` |

## CI and quality helpers

| File                 | Purpose                                                                                                    | Usage                                                  |
| -------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `ci-refs.py`         | Resolves the base and head commits of a CI run. A missing or zero ref fails instead of skipping checks.    | CI only                                                |
| `ci-quality.py`      | Runs the quality hooks on the direct tree difference between two commits, including force pushes.          | CI only                                                |
| `ci-pest-timings.py` | Writes the ten slowest tests from a JUnit report to the GitHub Actions summary.                            | `python3 bin/ci-pest-timings.py test-results/pest.xml` |
| `check-file-size.py` | File size ratchet: oversized files may shrink but not grow. The pre-commit hook is disabled at the moment. | `python3 bin/check-file-size.py`                       |

## One-off operational scripts

These scripts call external services. They are not part of the build or the tests.

| File                       | Purpose                                                                                                                                                                | Usage                                                                                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `brightdata-goto-test.php` | Compares three Bright Data SERP query variants for the social verify job. Sends real, billable requests (60 by default).                                               | `php artisan tinker --execute 'require base_path("bin/brightdata-goto-test.php");'` on a server with a working key |
| `extract-meta-page-ids.py` | Reads past Apify Facebook Ad Library runs and writes `page_ids.csv` and `page_ids.sql` with each profile's Meta page id. Read-only on Apify and writes to no database. | `APIFY_TOKEN=... bin/extract-meta-page-ids.py --since 2026-11-11T00:00:00Z`                                        |
